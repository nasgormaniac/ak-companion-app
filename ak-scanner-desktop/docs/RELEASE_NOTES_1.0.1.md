# Animal Kaiser Scanner Desktop 1.0.1

Windows desktop companion app for Animal Kaiser.

## Changes from 1.0.0

- Rarity badges stay readable when the application window is narrower.
- Card titles truncate cleanly when space is limited, without leaving extra space inside neighbouring cards.
- The home screen now has a **Card Catalogue** button that opens the reference spreadsheet in your default browser.

## Install

Download and run **Animal Kaiser Scanner Setup 1.0.1.exe**. Existing cards, images, and game port settings remain in `%APPDATA%\AK Scanner` when updating from 1.0.0. The catalogue spreadsheet requires an internet connection; the app's cards and game connection remain local. Automatic updates are not included.
