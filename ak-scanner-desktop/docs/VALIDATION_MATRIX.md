The card-code pattern and new-upload image size limit are shared JSON rules used by both renderer and main. SQLite remains the final integrity backstop. New card images are capped at the legacy 1024 KiB limit; images stored by the earlier 8 MiB desktop build can still be displayed. A successful HTTP 2xx means the local service accepted the request; the app cannot infer in-game completion from it.
